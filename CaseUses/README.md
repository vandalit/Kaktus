# CaseUses

Three small, deliberately different web-project anatomies for exploring how
code can later be mapped to visual components, views and relationships.

| Demo | Project shape | Start |
| --- | --- | --- |
| [01 · Mini Store](./01-mini-store/) | Full-stack storefront, local Node API and SQLite-backed orders | `cd CaseUses/01-mini-store && npm install && npm start` |
| [02 · Forma Studio](./02-forma-studio/) | Static multi-view creative site with original CSS motion | Open `index.html`, or serve the folder with a static server |
| [03 · Pulse Board](./03-pulse-board/) | Client-side dashboard with Kanban, filters, CRUD and local storage | Open `index.html`, or serve the folder with a static server |

The static demos run without a build step. The store is available at
<http://localhost:4171> after starting its local backend. Each project has its
own README with anatomy and run instructions.
