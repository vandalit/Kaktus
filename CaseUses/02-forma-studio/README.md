# 02 · Forma Studio

Sitio creativo estático de varias vistas, con composiciones originales,
transiciones y animaciones CSS. No depende de fragmentos de CodePen ni de
librerías JavaScript.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file
server. For example, from this directory run `python3 -m http.server 4172` and
open <http://localhost:4172>.

## Anatomy

- `index.html`: view structure and navigation.
- `styles.css`: responsive layout, original visual compositions and motion.
- `app.js`: view switching, URL hashes, project dialog and scroll reveals.
